
========================================================================
LAVI GROWTH TRACKER - PANDUAN LENGKAP PENGEMBANGAN & PENGGUNAAN
========================================================================

Author: Lathif Baska
Version: 1.1.0

Aplikasi ini adalah Tracker Kesehatan Keluarga berbasis React (Single Page Application)
yang fokus pada privasi (Local Storage) dan pemantauan klinis mandiri.

------------------------------------------------------------------------
1. STRUKTUR APLIKASI
------------------------------------------------------------------------
- App.tsx             : Logic utama, state management, routing (tabs), dan modal.
- types.ts            : Definisi tipe data (TypeScript Interfaces).
- utils.ts            : Helper untuk penyimpanan, kompresi gambar, tanggal, dan format data.
- data/symptoms.ts    : Daftar gejala penyakit untuk checklist (Sekarang ada di utils.ts).
- services/           : Integrasi sinkronisasi cloud & storage.
- components/UI.tsx   : Komponen dasar (Button, Input, Card, Modal).
- components/Features.tsx : Komponen fitur (Grafik, Tabel, Galeri, Form, Nutrisi).

------------------------------------------------------------------------
2. CARA EDIT KONTEN
------------------------------------------------------------------------

A. MENGUBAH DAFTAR GEJALA
   Buka file `utils.ts`, cari variable `SYMPTOM_LIST`.
   Formatnya adalah Array of Objects: { name: "Nama", emoji: "🤒" }.

B. MENGUBAH JUDUL / NAMA APLIKASI
   1. Buka `index.html` -> Ubah tag <title>.
   2. Buka `App.tsx` -> Cari text "Lavi Growth".
   3. Buka `metadata.json` -> Ubah "name".

C. MENGUBAH WARNA TEMA
   Aplikasi menggunakan Tailwind CSS. Warna utama didefinisikan di `index.html`
   dalam script `tailwind.config`. Ubah hex code di bawah `colors: { emerald: ... }`.

D. MENGUBAH DATA NUTRISI (ARTIKEL)
   Jika Anda ingin menambah, menghapus, atau mengedit daftar Vitamin/Mineral:
   1. Buka file `components/Features.tsx`.
   2. Cari variabel bernama `NUTRITION_DATA`.
   3. Ubah isinya sesuai format berikut:
      {
        name: "Nama Vitamin",
        func: "Fungsi/Manfaatnya...",
        source: "Sumber makanan...",
        color: "bg-warna-100 text-warna-700..." // Styling Tailwind
      }

------------------------------------------------------------------------
3. KEAMANAN & BACKUP
------------------------------------------------------------------------

A. PIN KEAMANAN
   - PIN disimpan di LocalStorage browser.
   - Saat PIN dibuat/diubah, file `PIN_LaviGrowth.txt` otomatis terdownload.
   - File ini berfungsi sebagai "kunci fisik" jika user lupa PIN.

B. BACKUP DATA
   - Fitur Export menghasilkan file `.json`.
   - File tersimpan di folder "Downloads" browser dengan nama `LaviGrowth_Backup_[Tanggal].json`.
   - PIN *TIDAK* disertakan dalam file backup JSON demi keamanan.
   - Foto tersimpan dalam bentuk Base64 string di dalam file JSON tersebut.
     (Hati-hati: Jika foto terlalu banyak, file JSON bisa sangat besar).

------------------------------------------------------------------------
4. RENCANA DEPLOYMENT (NETLIFY)
------------------------------------------------------------------------

Lavi Growth Tracker adalah aplikasi statis (Vite/React). Sangat mudah dideploy di Netlify.

Langkah-langkah:
1. Build aplikasi: Jalankan perintah `npm run build`.
   Ini akan menghasilkan folder `dist/`.
2. Login ke Netlify (https://www.netlify.com).
3. Drag & Drop folder `dist/` ke area deploy Netlify.
4. Selesai! Anda akan mendapatkan URL (misal: lavi-growth.netlify.app).

*Konfigurasi Tambahan untuk PWA (Progressive Web App)*:
Agar bisa diinstal seperti aplikasi native di HP:
1. Pastikan file `manifest.json` ada di public folder (sudah disiapkan oleh Vite biasanya).
2. Daftarkan Service Worker (opsional untuk offline mode penuh).

------------------------------------------------------------------------
5. MEMBUAT APLIKASI ANDROID (KODULAR)
------------------------------------------------------------------------

Anda bisa membungkus (wrap) website yang sudah dideploy di Netlify menjadi APK menggunakan Kodular.

Langkah-langkah di Kodular Creator:
1. Buat Project Baru.
2. Hapus Title Bar (Screen1 -> Show Options Menu: Uncheck, Title Visible: Uncheck).
3. Drag komponen "Web Viewer" ke layar.
4. Set "Home URL" pada Web Viewer ke URL Netlify Anda (https://lavi-growth.netlify.app).
5. (Opsional) Tambahkan logic "On Back Pressed" agar tombol back HP tidak langsung menutup aplikasi, tapi "Go Back" di web viewer.
   
   Logic Blocks:
   If (WebViewer1.CanGoBack)
      call WebViewer1.GoBack
   Else
      close application

6. Export -> Android App (.apk).

------------------------------------------------------------------------
TIPS PERFORMA
------------------------------------------------------------------------
Karena menggunakan LocalStorage untuk menyimpan gambar:
- Aplikasi otomatis mengompres gambar (resize & kualitas 70%) sebelum simpan.
- Jika browser terasa lambat, sarankan user untuk melakukan Export Backup, lalu Hapus Data Lama, atau hapus foto-foto lama.
