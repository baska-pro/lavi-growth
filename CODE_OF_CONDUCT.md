# Code of Conduct

Project ini mengharapkan interaksi yang profesional, relevan, dan menghormati pihak lain.

## Standar

- Fokus pada masalah teknis dan bukti yang dapat diverifikasi.
- Berikan kritik pada kode atau keputusan, bukan pada pribadi.
- Jangan mempublikasikan data pribadi, credential, atau informasi kesehatan pihak lain.
- Hindari spam, pelecehan, ancaman, dan konten diskriminatif.

## Penegakan

Pemilik repository dapat menyunting, menutup, mengunci, atau menghapus kontribusi yang melanggar pedoman ini serta membatasi partisipasi akun terkait.
