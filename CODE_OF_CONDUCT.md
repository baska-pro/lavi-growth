# Code of Conduct

Proyek ini mengharapkan komunikasi yang profesional, relevan, dan menghormati pengguna maupun kontributor lain.

Tidak diperbolehkan melakukan pelecehan, penghinaan, diskriminasi, spam, publikasi data pribadi, atau tindakan yang mengganggu kolaborasi teknis.

Maintainer berhak mengedit, menutup, atau menghapus kontribusi dan percakapan yang tidak sesuai dengan aturan repository atau lisensi proyek.

Untuk melaporkan masalah perilaku, hubungi maintainer melalui https://github.com/baska-pro.
