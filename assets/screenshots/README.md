# Screenshots

Tambahkan screenshot aplikasi yang sudah menggunakan data dummy/sintetis.

Rekomendasi nama file:

- `dashboard-mobile.webp`
- `dashboard-desktop.webp`
- `health-record.webp`
- `statistics.webp`
- `settings.webp`

Pastikan tidak ada nama lengkap, tanggal lahir nyata, catatan medis, foto pribadi, PIN, URL backend privat, atau credential pada screenshot.
