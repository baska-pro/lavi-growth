# Security Policy

## Versi yang didukung

| Versi | Dukungan |
| --- | --- |
| 1.x | Didukung |

## Data sensitif

Lavi Growth dapat menyimpan data kesehatan pribadi. Jangan pernah memasukkan data pengguna nyata, PIN, token, service-role key, secret, isi database, atau file backup privat ke repository.

Untuk backend Google Apps Script, ganti PIN awal sebelum penggunaan nyata. Untuk Supabase, gunakan anon/public key pada client dan jangan pernah memasukkan service-role key ke frontend.

## Melaporkan kerentanan

Jangan publikasikan detail eksploitasi atau data sensitif melalui issue publik. Laporkan secara privat kepada pemilik repository melalui profil GitHub:

https://github.com/baska-pro

Sertakan komponen terdampak, langkah reproduksi, dampak, dan saran mitigasi bila tersedia.
